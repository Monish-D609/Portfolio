# Project Instructions & Workflow Rules

## Git Workflow & Autonomous GitHub Sync
- **Automatic GitHub Push**: Whenever code modifications, feature updates, bug fixes, or documentation changes are completed in response to user requests, automatically stage all changes, create a clean descriptive commit, and push them directly to GitHub (`origin/main`) without requiring the user to explicitly ask.
- **Verification**: Always ensure builds/type-checks pass before committing and pushing.
- **Environment**: Operating System is Windows PowerShell. Use `;` instead of `&&` when chaining shell commands.
